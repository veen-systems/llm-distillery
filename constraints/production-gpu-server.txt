#
# Why this file exists: requirements.txt declares RANGES, and on 2026-08-09 five
# interpreters across four boxes all satisfied it with five different
# resolutions (torch 2.5.1 / 2.11.0 / 2.12.1 / 2.13.0; transformers 4.57.6 /
# 5.0.0 / 5.12.1 / 5.14.1). A range file cannot reproduce production. Numbers
# were published off the wrong interpreter that day and had to be redone.
#
# HOW TO USE
#   Build a box that must agree with production:
#     pip install -r requirements.txt -c constraints/production-gpu-server.txt
#   Diff a suspect box against production:
#     <that box's python> -m pip freeze | sort | diff - <(grep -v '^#' this file)
#
# DO NOT "upgrade" production to match a dev box. Changing torch/transformers
# under the student changes scores, and a change cannot be distinguished from
# the #95 |0.16| batch-composition noise floor without a full ADR-021
# ground-truth gate run per filter. Dev boxes move to production, never the
# reverse.
#

# defaults gives a different build with the same version number.
